# Undergraduate evidence images

The undergraduate page detects images in this directory automatically and
replaces the matching placeholder without any HTML changes.

Prepared from the supplied source documents:

- `transcript.jpg`
- `award-01.jpg` through `award-03.jpg`
- `campus-honor-01.jpg` through `campus-honor-03.jpg`
- `paper-framework-01.jpg` through `paper-framework-05.jpg`
- `software-01.jpg` through `software-03.jpg`
- `patent-01.jpg` through `patent-02.jpg`

Five supplied paper figures are rendered alongside the linked publication
list.

Landscape crops work best for papers and the transcript. Portrait or square
crops work best for certificates. Images are displayed with `object-fit:
contain`, so the full document remains visible.
