01

理解概念

回到当时的问题

用户希望逐步学习 earendil-works/pi，决定明天继续。当前只查阅架构与文档并形成路线，未安装、运行或完成代码实操。

定位与模块

Pi 提供模型接口 pi-ai、工具执行与状态管理 pi-agent-core、交互 CLI pi-coding-agent，以及终端 UI 等组件。模型输出工具调用，运行时执行工具并将结果追加回上下文。

消息流、工具执行和停止条件是学习主线。先读 agent-core 的 Message Flow / Event Flow，再看 pi-ai 的 Quick Start、Tools、Streaming、Stop Reasons。API 与安装方式可能变化，实操时核对对应版本文档。

四步练习计划

用：在练习项目要求修复函数并运行测试，观察 read/write/edit/bash。拆：追踪上下文→模型输出→工具执行→工具结果→下一次模型调用。

搭：用 agent-core 添加一个读取文件的工具，打印事件，试正常读取、文件不存在和轮数限制；再学 sessions、压缩和 extensions。测：自行准备 10–20 个任务，重置环境、记录轨迹、接入独立 Verifier 并重复采样。最后一步是本次建议的练习，不是声称仓库已有 RL 训练管线。
